% Demo resume for a fictional person (Alex Rivera). Never put real resume
% content in this file: it's committed and served by the public demo.
%
% It uses the same layout and macros as the owner's real resume template,
% so tailoring code written against one works on the other:
%   - \section*{Summary}: one plain paragraph
%   - Technical Skills: \resumeItem{\textbf{Category}: a, b, c}
%   - Entries: \resumeSubheading{4 args} + a nested list of
%     \resumeItem{\textbullet\ ...} bullets
%
% Differences from the original template:
%   - The pdfTeX-only lines (glyphtounicode, \pdfgentounicode) are wrapped
%     in \ifPDFTeX, so the file compiles under XeTeX engines like Tectonic
%     as well as pdfLaTeX. XeTeX output is already machine-readable.
%   - Unused packages removed (latexsym, marvosym, color, verbatim,
%     tabularx); fewer packages means fewer for the engine to fetch.
%   - The duplicated \setlength{\footskip} is set once.
%   - Date ranges consistently use -- (an en dash).
%
% The content (with LaTeX escapes like \& and \% removed) matches
% SEED_RESUME_V2 in seed.ts, which the demo comparisons were written
% against. Keep the two in sync.
